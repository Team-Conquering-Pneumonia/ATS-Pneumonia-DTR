# Tree-Based Dynamic Treatment Regimes for Community-Acquired Pneumonia

**ATS 2026 Poster**

## Overview

This repository accompanies the ATS 2026 poster presenting tree-based dynamic treatment regimes (DTRs) for antibiotic selection in community-acquired pneumonia (CAP). The DTRs provide personalized treatment recommendations that adapt based on patient characteristics, pneumonia severity, and viral etiology.

## Interactive Decision Trees

Explore the treatment decision trees interactively:

**[https://team-conquering-pneumonia.github.io/ATS-Pneumonia-DTR/](https://team-conquering-pneumonia.github.io/ATS-Pneumonia-DTR/)**

The trees display antibiotic recommendations stratified by pneumonia severity (mild / moderate / severe) and virus subgroup, with posterior estimates of 30-day mortality under each treatment arm.

## Methods

- **Design:** Target trial emulation using a VA pneumonia cohort
- **Method:** Tree-based DTR estimation (outcome-weighted learning)
- **Outcome:** 30-day all-cause mortality
- **Treatments:** Monotherapy vs. combination antibiotic regimens
